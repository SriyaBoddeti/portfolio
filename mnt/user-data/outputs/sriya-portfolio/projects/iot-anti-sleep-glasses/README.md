# IoT-Enabled Anti-Sleep Glasses

## Overview
A driver drowsiness detection system using eye-blink analysis to generate real-time alerts and reduce accident risk from driver fatigue.

## Problem Statement
Driver fatigue is a leading cause of road accidents. This project provides a wearable IoT-based solution that continuously monitors eye-blink patterns and alerts the driver before fatigue leads to accidents.

## Features
- Real-time eye-blink monitoring using IR sensors
- Instant audio/vibration alert on drowsiness detection
- Continuous sensor-based monitoring loop
- Low-power embedded hardware design

## Tech Stack
- IoT sensors (IR-based blink detection)
- Embedded Systems / Microcontroller
- Sensor data transmission module

## How It Works
1. IR sensor detects eye open/closed state continuously
2. Blink frequency and duration are analysed
3. If blink pattern indicates drowsiness (slow/prolonged closure), alert is triggered
4. Alert resets when driver is active again
